# 员工状态识别规则

> 书写说明：每个判定维度用 `### 标题` 起一节，节内用 `- 键：值` 描述。
> - `字段名`：最终输出 JSON 中的字段名，需与本节标题语义一致（省略时取标题）。
> - `合法取值`：该字段所有允许的输出值，用 `/` 分隔。
> - `违规取值`：出现哪些取值即判定为违规（省略时程序会依据字段语义自动推断）。
> - `判定标准`：模型据以判定的客观依据。
>
> 「无人时的默认取值」请写在判定标准里，例如「画面中无人时判定为『是』」。

### 1. 是否所有人员都佩戴安全帽
- 字段名：是否所有人员都佩戴安全帽
- 合法取值：是 / 否
- 违规取值：否
- 判定标准：观察图像中所有可见人员的头部（含被遮挡部分，若头部完全不可见则不计入），只要存在任意一名人员头部未佩戴安全帽，即判定为「否」；所有人员均规范佩戴安全帽时判定为「是」。画面中无任何人员时判定为「是」。

### 2. 是否存在人员在岗使用手机
- 字段名：是否存在人员在岗使用手机
- 合法取值：是 / 否
- 违规取值：是
- 判定标准：若图像中存在人员手持手机、低头注视手机屏幕、将手机贴近耳部通话等正在使用手机的行为，判定为「是」；人员未持有手机或手机仅放置于桌面/口袋中未被使用时判定为「否」。画面中无任何人员时判定为「否」。

### 3. 是否存在无人看管的作业工具
- 字段名：是否存在无人看管的作业工具
- 合法取值：是 / 否
- 违规取值：是
- 判定标准：若图像中存在电钻、扳手、切割机、电动工具等作业工具被随意放置在地面、设备旁、走道等位置，且周边没有人员在岗看管（无人或最近人员未在工具附近作业），判定为「是」；工具均收纳于工具箱/工具柜中，或工具紧邻正在作业的人员时判定为「否」。

### 4. 是否存在人员未按规定穿戴防护装备
- 字段名：是否存在人员未按规定穿戴防护装备
- 合法取值：是 / 否
- 违规取值：是
- 判定标准：除安全帽外，检查图像中人员是否按规定穿戴反光背心、防护手套、防护眼镜、防砸鞋等防护装备。若存在任意一名已进入作业区域的人员未穿戴上述应当穿戴的防护装备，判定为「是」；所有人员均规范穿戴时判定为「否」。画面中无任何人员时判定为「否」。

### 5. 作业区域是否存在人员吸烟或明火
- 字段名：作业区域是否存在人员吸烟或明火
- 合法取值：是 / 否
- 违规取值：是
- 判定标准：若图像中存在人员吸烟动作、点燃的香烟、打火机火焰、明火或烟雾等迹象，判定为「是」；画面中未见任何吸烟行为、明火或烟雾迹象判定为「否」。画面中无任何人员时判定为「否」。
