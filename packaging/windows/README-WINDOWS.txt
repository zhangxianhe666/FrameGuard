帧防 FrameGuard · Windows 使用说明
==================================

启动
----
安装完成后，从开始菜单或桌面快捷方式打开「FrameGuard」。
程序会在本机启动服务并自动用默认浏览器打开操作界面，地址默认是：

    http://127.0.0.1:7891

若该端口已被占用，程序会自动顺延到下一个可用端口（可在任务管理器里看命令行参数，
或查看下面的日志文件）。在界面「⑥ 模型配置 → API Key」填入 Key 即可开始分析，
无需手工创建 .env。

关闭
----
FrameGuard 是以本机 Web 服务的形式运行的，关闭浏览器标签并不会停止程序。
要真正退出，请用开始菜单里的「Stop FrameGuard」，或双击安装目录下的
stop-frameguard.bat。

报告与缓存位置
--------------
    %APPDATA%\FrameGuard\
        outputs\   每次任务的报告（HTML / Markdown / CSV / JSON）
        cache\     抽帧缓存、演示图片、运行日志与崩溃日志
        .env       可选，可在此配置 FRAMEGUARD_API_KEY 等（升级不丢）

卸载程序不会删除上面这个目录，需要清理请手动删除。

首次运行被 Windows 拦下？
-------------------------
安装包未做商业代码签名，SmartScreen 可能提示「Windows 已保护你的电脑」。
点「更多信息」→「仍要运行」即可（只需一次）。

启动没反应怎么办？
------------------
先看 %APPDATA%\FrameGuard\cache\crash.log，里面会有完整的错误堆栈。
